# ROADMAP v3 — Merchant template UI builder

**You are done with v3 when** the seeded merchant can, from the demo-gated builder, clone a library preset, rename a column label and hide a column, reorder and resize blocks into a side-by-side row, watch it in a live preview that is **byte-identical** to the production render, and save it — producing **exactly one** new `Template` row with `parentTemplateId` set, `isHead` flipped on the parent, and `Merchant.defaultTemplateId` repointed, with **zero mutation** of the parent's `layoutSchema`; the next bill from either write path renders on the new layout while **every already-issued bill renders exactly as before**; an invalid layout is unsavable and is named in the UI *before* Save is ever enabled; and **every v1 and v2 test is still green**.
